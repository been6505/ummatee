เอา Webhook URL จากไหน?
  • ในห้อง Discord กด ⚙ แก้ไขช่อง → การเชื่อมต่อ (Integrations) → Webhooks → สร้าง Webhook → คัดลอก URL มาวาง
  • ข้อความใน Discord ไม่มีชื่อและเบอร์ผู้แจ้ง มีลิงก์เข้า CENTRAL (ต้องใช้รหัส)
  • ลบ URL แล้วบันทึก = ยกเลิกการเชื่อม

รับตำแหน่งทีมทาง SMS ไม่ต้องใช้เน็ตฝั่งทีม

ทีมที่ไม่มีเน็ตกดส่ง SMS ถึงเบอร์ศูนย์ได้ (ปุ่ม "ส่งทาง SMS" ในแอป/หน้าทีม) · ให้มือถือ Android เบอร์ศูนย์ส่งต่อ SMS เข้าระบบ ตำแหน่งจะขึ้นแผนที่ CENTRAL เอง

ตั้งค่ามือถือเบอร์ศูนย์ (Android · ครั้งเดียว)
  • ตั้งเบอร์ศูนย์ที่หน้า "จัดทีม" ให้ตรงกับมือถือเครื่องนี้ (ทีมจะส่ง SMS มาที่เบอร์นี้)
  • ติดตั้งแอปฟรี SMS to URL Forwarder (หรือแอปส่งต่อ SMS ที่ส่ง HTTP ได้) บนมือถือเบอร์ศูนย์
  • เพิ่มกฎ: ผู้ส่ง = ทุกเบอร์ (หรือใส่คำ #HM:) · URL = ลิงก์รับ SMS ด้านบน · วิธี = POST
  • เปิดให้แอปทำงานเบื้องหลังและไม่ถูกจำกัดแบตเตอรี่ · ทดสอบโดยให้ทีมกด "ส่งทาง SMS" แล้วดูหมุดบนแผนที่
  • ลิงก์นี้เป็นความลับ ใครมีลิงก์ส่งตำแหน่งปลอมได้ · หลุดเมื่อไรกด "สร้างลิงก์ใหม่"

AI HELP Local AI / คลาวด์

ตัวรัน AI
เชื่อมต่อไม่ได้?
  • มือถือ / เครื่องที่ไม่ได้รัน AI เอง: เลือก "คลาวด์ (ใช้ได้ทุกเครื่อง)" ใช้ AI SEA-LION (เก่งภาษาไทย) บน Cloudflare ของระบบ ใช้ได้ทันที ข้อมูลส่งผ่านเซิร์ฟเวอร์ CENTRAL · ตัว Hermes ต้องรันในเครื่อง
  • ตัวรันในเครื่อง (Hermes Agent / Ollama / LM Studio): ตั้งค่าเก็บเฉพาะเบราว์เซอร์นี้ และเบราว์เซอร์เรียกเครื่อง AI โดยตรง ข้อมูลไม่ผ่านเซิร์ฟเวอร์ CENTRAL
  • Hermes Agent: เปิด API server ของ Hermes (OpenAI-compatible) แล้วใส่ที่อยู่ เช่น http://localhost:8642/v1 และอนุญาต origin https://central.helpme4u.com (CORS)
  • Ollama: ollama pull hermes3 แล้วรันด้วย OLLAMA_ORIGINS=https://central.helpme4u.com ollama serve
  • LM Studio: เปิด Local Server และติ๊ก Enable CORS
  • ใช้จากเครื่องอื่นในวง LAN: ใส่ IP ของเครื่องที่รัน AI แทน localhost (ต้องเป็น https หรือเบราว์เซอร์อาจบล็อก)

ประวัติการเปลี่ยนแปลง 180 วัน
