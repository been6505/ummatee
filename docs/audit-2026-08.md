## บั๊กที่เจอ — ทุกตัว "เงียบ" คือไม่มี error ให้เห็น

ทั้งหมดนี้หน้าเว็บทำงานดูปกติ แต่แสดงข้อมูลผิดหรือขาดหาย

### 1. หน้า "งานของฉัน" บอกครึ่งทีมว่าไม่มีงาน

`/admin/my-work` เปิดให้ 4 role แต่ `firestore.rules` ให้สิทธิ์ไม่เท่ากัน

| | `contentPosts` | `boardCards` |
|---|---|---|
| `social` | ✅ | ❌ ถูกปฏิเสธ |
| `field` | ❌ ถูกปฏิเสธ | ✅ |

listener ที่ล้มถูกกลืน error → หน้าขึ้นว่า **"ยังไม่มีงานที่มอบหมายให้คุณ"** ทั้งที่มีงานอยู่

เจอแบบเดียวกันอีก 2 จุด: ปฏิทินคอนเทนต์ (ช่องเลือกแคมเปญว่างตลอดสำหรับ `social`) และหน้าแคมเปญ (**แสดงเลข 0** ซึ่งอ่านได้ว่า "ไม่มีคอนเทนต์ผูกอยู่")

> 🛡️ `guardRulesParity.test.js` อ่าน `firestore.rules` จริงแล้วเทียบกับทุกหน้า — คู่ใหม่ที่ไม่ตรงจะทำให้เทสต์แดง

### 2. การแนบรูปในรีวิวสินค้าไม่เคยทำงานเลย

บั๊ก 2 ตัวซ้อน แต่ละตัวก็พอทำให้พังเองอยู่แล้ว

1. `uploadToCloudinary` คืน `{url, type, publicId}` แต่โค้ดเก็บทั้ง object → `<img src="[object Object]">`
2. ตัวตรวจ URL ไม่ยอมรับ **จุลภาค** แต่ URL จริงทุกใบมี `f_auto,q_auto` ติดมาเสมอ

**เทสต์เดิมผ่านเพราะ fixture เขียนเองให้สะอาดเกินจริง** — เป็นรูปแบบเดียวที่แอปไม่เคยสร้าง
เทสต์ใหม่สร้าง fixture จาก `optImg()` จริง และ assert ว่ามีจุลภาคอยู่

### 3. เงินบริจาคที่ไม่มีวันที่ หายจากทุกยอดรวม

ฟอร์มตรวจจำนวนเงินแต่ไม่ตรวจวันที่ และช่อง `<input type="date">` ลบให้ว่างได้

```
''.startsWith('2026-08')  → false   ไม่นับในยอดเดือนนี้
''.slice(0,7) เป็นค่าว่าง  → false   ไม่เข้ากราฟรายเดือน
'' >= '2026-08-01'        → false   หายทั้งแถวเมื่อกรองช่วงวันที่
```

แถวยังโผล่ในตารางตอนไม่กรอง — **เงินอยู่ในฐานข้อมูล แต่ไม่ปรากฏในตัวเลขไหนเลย**

### 4. `/admin/shop/feedback` เรนเดอร์ในเชลล์ public

มี nav สาธารณะ + ปุ่มบริจาคลอย + วิดเจ็ตแชท และ**โหมดปิดปรับปรุงจะบังหน้านี้จากทีมงานตอนที่ต้องใช้พอดี**

### 5. `fetchPriority` ถูก React ทิ้งทั้ง attribute

React 18 ไม่รู้จัก camelCase → รูปใหญ่สุดของหน้าแรกไม่เคยได้ priority hint เลยสักครั้ง

### 6. กฎกัน iPhone ซูม "มีอยู่แล้ว" แต่ไม่เคยทำงาน

เขียนเป็น `input, select, textarea` เปล่า ๆ แล้วหวังพึ่งลำดับไฟล์
แต่ลำดับช่วยได้เฉพาะตอน specificity **เท่ากัน** — `.shop-search` (0,1,0) ชนะ element selector (0,0,1) เสมอ

### 7. จุดเลื่อนภาพ 7×7px กดไม่โดน

39 จุดในหน้า `/missions` เทียบกับเกณฑ์ iOS ที่ 44pt
ขยายพื้นที่กดเป็น 19×34 (**เท่าระยะห่างระหว่างจุดพอดี** — กว้างกว่านี้จะทับจุดข้างๆ แล้วกดจุดที่ 1 จะไปโดนจุดที่ 2)

### 8. กด Tab แล้วไม่รู้ว่าโฟกัสอยู่ตรงไหน

3 ช่องที่เขียน `outline:none` โดยไม่ใส่อะไรแทน (แชทหน้าเว็บ, แชทแอดมิน, ค้นหาในเมนู)

## ยังไม่ได้แก้ (ตั้งใจ)

### `match /boards/{id}` ไม่มีโค้ดไหนใช้

บอร์ดวางแผนใช้แค่ `boardLists` กับ `boardCards` — ดูเหมือนของเหลือจากเวอร์ชันเก่า
**ไม่ลบเพราะอาจมีเอกสารค้างอยู่ใน production ซึ่งอ่านไม่ได้จากที่นี่**

### แยก `admin.css` ออกจากหน้า public

`admin.css` = **136KB จาก 328KB (41%)** และคนเข้าเว็บสาธารณะโหลดไปด้วยทั้งที่ไม่ได้ใช้

**ไม่ทำ** เพราะหน้า checkout กับ order-status ใช้คลาส `admin-*` อยู่จริง (7 ตระกูล / 42 กฎ กระจายทั่วไฟล์ และ 46 จุดอยู่ใน media query)
ได้ ~16kB gzip จาก 155kB (~10%) แต่เสี่ยงกับหน้าจ่ายเงิน — ไม่คุ้มถ้าทดสอบการซื้อจริงไม่ได้

## หมายเหตุสำหรับคนที่มาทำต่อ

**บั๊กในระบบนี้มักไม่มี error ให้เห็น** — listener เกือบทุกตัวดัก error ไว้เงียบ ๆ แล้วหน้าก็แสดงว่า "ไม่มีข้อมูล"
ซึ่งแยกไม่ออกจาก "ไม่มีข้อมูลจริง ๆ" การอ่านโค้ดอย่างเดียวจึงไม่พอ ต้อง**เทียบสองฝั่ง** (โค้ด ↔ rules) หรือ**วัดค่าจริงในเบราว์เซอร์**

เทสต์ 3 ตัวนี้มีไว้กันบั๊กทั้งตระกูล ไม่ใช่เคสเดียว:

- `guardRulesParity.test.js` — สิทธิ์ของหน้า เทียบกับ rules
- `collectionRulesParity.test.js` — collection ที่ใช้ เทียบกับ rules
- `workSources.test.js` — ตารางสิทธิ์ของ "งานของฉัน" เทียบกับ rules

ทั้งสามอ่าน `firestore.rules` ของจริง ไม่ได้ hard-code ไว้ — และ**ทดสอบแล้วว่ามันแดงจริงเมื่อมีอะไรผิด** ไม่ใช่ผ่านฟรี ๆ
